Comment ça marche

Cette plateforme analyse vos documents pour en extraire les concepts clés et les organiser automatiquement dans un espace interactif.

pdf
analyse
carte

Chaque point représente une idée ou un concept. Plus un point est grand, plus le concept est central dans votre document.

Ajuster la carte (Force des liens)

Le curseur "Force des liens" contrôle la précision de l'affichage sémantique :

bas
haut

Un réglage bas montre toutes les associations subtiles, tandis qu'un réglage haut met en lumière la structure logique principale.

Lignes de tension rouges

Les lignes vibrantes visualisent les paradoxes et les oppositions directes détectées dans le texte.

idée a
opposition
idée b

Elles indiquent des points de friction où le texte présente des arguments contradictoires qui s'excluent mutuellement.

Double-clic (Synthèse)

Double-cliquez sur un espace vide pour fusionner les deux idées les plus proches en un nouveau concept.

heidegger
turing
✦ la machine comme oubli de l'être

Le nouveau concept apparaît sous la forme d'un point bleu pulsant, créant une synthèse inédite entre vos documents.
