# Philosophers Discovery Atlas

A static, dependency-free atlas for exploring Deniz C. O.'s philosopher dataset as thinkers, concepts, problems, supports, oppositions, tensions, threads, and comparisons.

## Files

- `index.html` — app shell and design.
- `app.js` — interaction logic, parser, graph, filters, comparison, threads, inspector.
- `philosophers-data.json` — canonical dataset used by the app.

## Use

Open `index.html` from a static server, GitHub Pages, or any web host.

Manual upload supports:

- original `philosophers.json`
- enriched `.txt`
- grouped/reflowed `.txt`

## Dataset

- 119 thinkers
- 839 statements
- 952 support/opposition links
